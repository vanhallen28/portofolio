PORTOFOLIO v0.2.1 — BACA INI DULU
================================================================

Perbaikan: saat membuka studi kasus lain (kartu "Ruang berikutnya"
di bawah studi kasus, atau tombol "Lihat studi kasus" di ruang),
halaman baru sekarang selalu mulai dari paling atas.

- Tombol Back browser tetap kembali ke posisi Anda sebelumnya.
- Link ke bagian tertentu (mis. Karya di breadcrumb) tetap menuju
  bagian itu.
- Menu header di halaman studi kasus (Karya, Layanan, …) sekarang
  berhenti tepat di bagiannya di beranda.
- "Kembali ke atas" di footer sekarang benar-benar sampai ke atas.

Tidak ada SQL baru. Tidak ada file yang dihapus. Tidak ada yang
perlu diubah di admin.


PASANG (salin-tempel di Terminal)
----------------------------------------------------------------

  cd ~/Documents/Virgiawan/PROJECT/portofolio
  unzip -o ~/Downloads/portofolio-v0.2.1.zip -d .
  npm install
  npm run build
  git add -A
  git commit -m "v0.2.1: studi kasus baru selalu mulai dari atas"
  git push

Push berhasil bila diakhiri "main -> main" dan tidak ada baris
"error:" atau "fatal:". Cek dengan: git status

Setelah Vercel selesai deploy (status Ready), coba: buka satu studi
kasus, gulir ke bawah, klik "Ruang berikutnya". Halaman baru harus
terbuka di bagian atas.
