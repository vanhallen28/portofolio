1. PASANG (salin-tempel di Terminal)
----------------------------------------------------------------

  cd ~/Documents/Virgiawan/PROJECT/portofolio
  unzip -o ~/Downloads/portofolio-v0.2.8.zip -d .
  npm install
  npm run build
  git add -A
  git commit -m "v0.2.8: ruang RUA"
  git push

Push berhasil bila diakhiri "main -> main" dan tidak ada baris
"error:" atau "fatal:". Cek dengan: git status


2. SUPABASE: TAMBAHKAN RUA (sekali saja)
----------------------------------------------------------------

Isi situs live diambil dari database, jadi ruang RUA baru muncul
setelah SQL ini dijalankan.

a. Tunggu deploy v0.2.8 di Vercel berstatus Ready (gambar dan file
   preview baru ada setelah deploy).

b. Di Terminal, salin isi SQL-nya:

     pbcopy < supabase/updates/v0.2.8.sql

c. Buka Supabase → SQL Editor → New query, tempel (Cmd+V), Run.
   Hasilnya: "Success. No rows returned". Itu normal; Supabase
   tidak menampilkan pesan selesai dari SQL ini.

   SQL ini hanya menambah yang belum ada: proyek RUA di belakang
   ruang terakhir, studi kasusnya, dan namanya di deretan klien.
   Tiga kalimat yang menghitung karya hanya diganti bila masih sama
   persis dengan bawaan v0.2.7; kalimat yang sudah Anda ubah di
   admin tidak disentuh. Menjalankannya lagi tidak mengubah apa pun.

   v0.2.7.sql belum pernah dijalankan? Jalankan v0.2.7.sql dulu
   dengan cara yang sama, baru v0.2.8.sql.

d. Cek hasilnya, masih di SQL Editor:

     select slug, sort, published from public.projects order by sort;

   Benar bila baris terakhir: rua, published = true.

e. Situs memuat isi baru dalam ± 10 menit. Supaya langsung tampil:
   buka /admin → Pengaturan situs → Simpan (tanpa mengubah apa pun),
   lalu buka beranda dan tekan Cmd+Shift+R.
