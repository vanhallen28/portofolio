1. PASANG (salin-tempel di Terminal)
----------------------------------------------------------------

  cd ~/Documents/Virgiawan/PROJECT/portofolio
  unzip -o ~/Downloads/portofolio-v0.2.13.zip -d .
  npm install
  npm run build
  git add -A
  git commit -m "v0.2.13: ruang Ranum"
  git push

Push berhasil bila diakhiri "main -> main" dan tidak ada baris
"error:" atau "fatal:". Cek dengan: git status


2. SUPABASE: RUANG RANUM (sekali saja)
----------------------------------------------------------------

a. Tunggu deploy v0.2.13 di Vercel berstatus Ready.

b. Bila SQL v0.2.12 (Ciri) belum Anda jalankan, jalankan dulu
   seperti di BACA-INI-v0.2.12.txt.

c. Di Terminal:

     pbcopy < supabase/updates/v0.2.13.sql

d. Supabase → SQL Editor → New query, tempel (Cmd+V), Run.
   Hasilnya "Success. No rows returned" (itu normal).

   SQL ini menambah ruang Ranum di BELAKANG ruang terakhir Anda,
   studi kasusnya, dan nama Ranum di ujung deretan "Proyek untuk"
   (dilewati bila deretannya sudah berisi 12 nama). Urutan ruang yang
   sudah Anda atur tidak disentuh. Kalimat "sebelas karya" hanya
   diganti bila belum pernah Anda ubah. Menjalankannya lagi tidak
   mengubah apa pun.

e. Buka /admin → Pengaturan situs → Simpan (tanpa mengubah apa pun),
   lalu buka beranda dan tekan Cmd+Shift+R.

Mau Ranum di posisi lain? Atur urutannya di Admin → Proyek seperti
biasa.
