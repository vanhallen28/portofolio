Zip ini berisi seluruh proyek, termasuk v0.2.4 dan v0.2.5. Kalau
versi itu belum dipasang, cukup pasang yang ini.

Yang berubah: animasi situs, gaya situs, komponen ruang, form admin
Proyek, isi bawaan, uji. Tidak ada file yang dihapus, tidak ada
migrasi database.


1. PASANG (salin-tempel di Terminal)
----------------------------------------------------------------

  cd ~/Documents/Virgiawan/PROJECT/portofolio
  unzip -o ~/Downloads/portofolio-v0.2.6.zip -d .
  npm install
  npm run build
  git add -A
  git commit -m "v0.2.6: efek gulir berbeda di setiap ruang karya"
  git push

Push berhasil bila diakhiri "main -> main" dan tidak ada baris
"error:" atau "fatal:". Cek dengan: git status


2. SUPABASE
----------------------------------------------------------------

Tidak perlu menjalankan SQL. Proyek di database Anda otomatis
memakai "Otomatis", yang dengan urutan ruang sekarang menghasilkan
efek seperti daftar di atas.

Mau mengganti efek satu ruang? Admin → Proyek → (nama proyek) →
Tampilan visual → "Efek layar saat digulir" → Simpan.
Catatan: "Otomatis" memilih berdasarkan urutan. Kalau urutan ruang
diubah, efeknya ikut bergeser; pilih efek tertentu bila ingin tetap.

Ruang Biansa masih kosong di situs live? Jalankan langkah 2 di
docs/updates/BACA-INI-v0.2.4.txt (supabase/updates/v0.2.2.sql).
