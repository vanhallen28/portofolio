PORTOFOLIO v0.1.0 — BACA INI DULU
================================================================

Ini rilis pertama: situs portofolio + panel admin.
Zip ini berisi seluruh kode proyek. Pasang ke repo GitHub
vanhallen28/portofolio dengan perintah di bawah.


1. PASANG (salin-tempel di Terminal)
----------------------------------------------------------------

Pertama kali (repo belum ada di laptop):

  cd ~/Documents/Virgiawan/PROJECT
  git clone https://github.com/vanhallen28/portofolio.git
  cd portofolio
  unzip -o ~/Downloads/portofolio-v0.1.0.zip -d .
  npm install
  npm run dev

Buka http://localhost:3000 (situs) dan http://localhost:3000/admin
(kata sandi mode lokal: portofolio-lokal). Bila sudah oke:

  git add -A
  git commit -m "v0.1.0: portofolio + panel admin"
  git push

Catatan: README.md dari GitHub akan tertimpa README baru. Itu memang
disengaja.


2. SAMBUNGKAN KE SUPABASE & VERCEL
----------------------------------------------------------------

Ikuti README.md langkah 2 sampai 6:

  2. Buat proyek Supabase baru (region Singapore)
  3. SQL Editor: jalankan supabase/migrations/0001_init.sql,
     lalu supabase/seed.sql
  4. Buat akun admin + jalankan SQL insert into public.admins
  5. Isi .env.local, lalu: npm run doctor   (semua harus ✓)
  6. Import repo di Vercel + isi 2–3 variabel lingkungan, Deploy

Tidak ada file yang dihapus di versi ini.
