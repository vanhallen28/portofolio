# Lisensi font

Semua font di folder ini berlisensi SIL Open Font License 1.1 dan diambil dari paket npm @fontsource:
Schibsted Grotesk, Marcellus, Plus Jakarta Sans, Archivo Black, Unbounded, Cormorant Garamond, Host Grotesk, Quicksand, Lora, Anton, Instrument Serif.
Teks lisensi lengkap: https://openfontlicense.org

VALE Display (vale-display.woff2), LOMA Display (loma-display.woff2), dan RUA Display (rua-display.woff2) adalah huruf judul merek VALE, Loma, dan RUA. Ketiganya diambil apa adanya dari file situs proyek itu (hanya berisi huruf yang dipakai situsnya) dan di sini hanya dipakai untuk menampilkan karya tersebut: judul ruang, studi kasus, dan deretan klien. Lisensinya mengikuti lisensi huruf di proyek klien.

Alte Haas Grotesk (ciri-display.woff2, © 2007 Yann Le Coroller) adalah huruf situs Ciri. Diambil apa adanya dari file situs Ciri (berat Regular, huruf Latin dasar) dan di sini hanya dipakai untuk menampilkan karya Ciri: judul ruang, studi kasus, dan deretan klien. Lisensinya mengikuti lisensi huruf di proyek klien.

Playfair Display (ranum-display.woff2, © 2017 The Playfair Display Project Authors) adalah huruf serif situs Ranum, berlisensi SIL Open Font License 1.1. Diambil apa adanya dari file situs Ranum (berat Regular, huruf Latin dasar) dan di sini dipakai untuk menampilkan karya Ranum: judul ruang, studi kasus, dan deretan klien.
